# BDA menu icon

`road_rash_3do_icon.png` uses the Road Rash logo from the original 3DO title image in `local-data/3do-decomp-road-rash/assets/road_rash_banner.png`. It takes source pixels `x=64..255, y=43..148` and centers them on a 192×192 dark background. The BDA packer generates the four firmware icon sizes from this PNG.

This is original game artwork, separate from the port's source-code license.
